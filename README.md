# Laboratório de Programação 2 - Estruturas de Dados (TADs)

Implementação e testes de Tipos Abstratos de Dados (TADs) em linguagem C:
- **Pilha** (`pilha.c` / `pilha.h`)
- **Fila** (`fila.c` / `fila.h`)
- **Lista** (`lista.c` / `lista.h`)

## Como compilar e executar

### Pelo Terminal
```bash
gcc *.c -o main.exe
./main.exe
```

### Pelo VS Code
- Abra o projeto no VS Code.
- Pressione **F5** para compilar e executar automaticamente com as configurações do `.vscode/`.
